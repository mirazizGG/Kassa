  1-QADAM.  PowerShell ni ochish
----------------------------------------------------------------

  - "Start" tugmasini bosing
  - "PowerShell" deb yozing
  - "Windows PowerShell" ni oching (oddiy oyna, Administrator shart emas)


----------------------------------------------------------------
  2-QADAM.  Buyruqlarni kiritish
----------------------------------------------------------------

  Quyidagi 3 qatorni BIRMA-BIR ko'chirib qo'ying, har biridan keyin
  ENTER bosing:

      git clone https://github.com/mirazizGG/Kassa.git C:\SmartKassa
      cd C:\SmartKassa
      .\deploy\install-smartkassa.ps1


  AGAR 1-qator "git ... topilmadi" (yoki "not recognized") desa —
  demak Git hali yo'q. U holda yuqoridagilar o'rniga SHU BITTA
  qatorni kiriting:

      irm https://raw.githubusercontent.com/mirazizGG/Kassa/main/deploy/install-smartkassa.ps1 | iex

  (bu Git ni ham o'zi o'rnatadi va kodni C:\SmartKassa ga oladi)


----------------------------------------------------------------
  3-QADAM.  Ruxsat berish va kutish
----------------------------------------------------------------

  - "Administrator huquqi kerak" degan oyna chiqsa — "Ha" (Yes) deng
  - Yangi oyna ochiladi va o'rnatish boshlanadi

  AGAR "kompyuterni QAYTA YOQING" degan yozuv chiqsa:
      - kompyuterni o'chirib-yoqing

            .\deploy\install-smartkassa.ps1


----------------------------------------------------------------
  O'RNATUVCHI O'ZI BAJARADIGAN ISHLAR
----------------------------------------------------------------

  1. Python bor-yo'qligini tekshiradi -> yo'q bo'lsa o'rnatadi
  2. Git bor-yo'qligini tekshiradi   -> yo'q bo'lsa o'rnatadi
  3. Loyiha kodini tayyorlaydi (klon / yangilash)
  4. Kutubxonalarni o'rnatadi (pip install)
  5. backend\.env faylini yaratadi (maxfiy kalit bilan)
  6. Do'kon (LAN) rejimiga sozlaydi
  7. Dasturni ishga tushiradi (port 8000)
  8. Kompyuter yonganda avtomat ishga tushishini o'rnatadi
